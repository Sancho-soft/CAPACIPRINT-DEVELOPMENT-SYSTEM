1. EXECUTIVE SUMMARY & ACTOR ROLES
================================================================================
CapaciPrint integrates multi-branch printing shop operations into a unified 
digital workflow. The system coordinates 9 distinct user actors across 20 modules:

  1. Super Admin       : Full system control, role permissions, emergency recovery.
  2. Owner / Executive : Financial dashboards, branch performance, procurement approvals.
  3. System Admin      : User accounts, branch infrastructure, machine catalogs.
  4. Branch Manager    : Capacity scheduling, branch workload, employee management.
  5. Production Officer: Production planning, multi-branch job scheduling.
  6. Customer Service  : Customer CRM, request intake, quotation, payments, claiming.
  7. Layout Designer   : Artwork preparation, layout proofs, revision approvals.
  8. Production Tech   : Job execution, machine operations, material deductions.
  9. Customer          : Request wizard, quote approval, order tracking, claiming.

MODULE 1: AUTHENTICATION & ACCOUNT ACCESS
--------------------------------------------------------------------------------
- Purpose: Secure user authentication, session control, and role redirection.
- Key Actors: All Users.
- Implementation Details:
  * Handled via App\Http\Controllers\Auth\LoginController & RegisterController.
  * Checks encrypted credentials (bcrypt) and verifies user status.
  * Role Redirection: Upon successful login, the system automatically redirects
    the user to their designated dashboard:
      - Admin / Super Admin -> /admin/dashboard
      - Customer            -> /customer/dashboard
      - Customer Service    -> /staff/dashboard
      - Branch Manager      -> /manager/dashboard
      - Production Staff    -> /production/dashboard
      - Inventory Staff     -> /inventory/dashboard
      - Management / Owner  -> /management/dashboard
  * Fast Role Switcher (/switch-role/{role}) included for rapid testing and presentations.

3. DETAILED BREAKDOWN OF PRODUCTION MODULES (MODULES 7 TO 8)
================================================================================

--------------------------------------------------------------------------------
MODULE 7: QUOTATION & ESTIMATION
--------------------------------------------------------------------------------
- Purpose: Accurate cost calculation, quotation generation, sending, and approval.
- Key Actors: Customer Service / Sales, Customer.
- Implementation Details:
  * Controllers: 
    - App\Http\Controllers\Staff\QuotationController
    - App\Http\Controllers\Customer\QuotationController
  * Step-by-Step Process:
    1. Pricing Matrix Evaluation: Staff references PricingRule model to automatically
       derive base cost, material rate, and finishing surcharges based on quantity and size.
    2. Quotation Generation: System generates a unique quotation number (QT-XXXXXX),
       sets an expiration date (valid_until), and stores the financial breakdown.
    3. Customer Notification: Automated customer notification is logged in the database.
    4. Customer Decision:
       - Confirm: Customer accepts the quote, advancing the request to the payment stage.
       - Decline: Customer rejects the quote with feedback.
       - Download: Printable/downloadable summary for customer records.

--------------------------------------------------------------------------------
MODULE 8: PRINT JOB MANAGEMENT & EXECUTION
--------------------------------------------------------------------------------
- Purpose: Order conversion, branch production scheduling, shop-floor execution,
  and automated inventory consumption.
- Key Actors: Customer Service, Branch Manager, Production Operator, Customer.
- Implementation Details:
  * Controllers:
    - App\Http\Controllers\Staff\OrderController
    - App\Http\Controllers\Manager\ProductionPlanningController
    - App\Http\Controllers\Production\JobController
  * Step-by-Step Process:
    1. Order Creation & Payment Verification: Once payment is submitted by customer,
       staff verifies payment and creates the official Order (#ORD-XXXXX).
    2. Production Job Initialization: Staff converts the order into a Production Job
       (#JOB-XXXXXX) with priority tags ('normal', 'rush', 'urgent').
    3. Multi-Branch Planning & Machine Assignment: Branch Manager assigns the job
       to an active production technician and an available branch machine.
    4. Shop-Floor Production:
       - Operator changes status: 'assigned' -> 'in_production' -> 'completed'.
       - Automatic Material Deduction: Upon starting production, the system automatically
         deducts required paper/material units from BranchInventory and logs a
         StockMovement (Stock Out) record with job reference.
       - Delay Handling: If delayed, reasons are logged and alerts are sent to managers.
    5. Order Completion & Claim Generation:
       - When production completes, a ClaimReference is generated with a unique QR code.
       - Staff uses the Claim Scanner (/staff/claim-scanner) to verify QR code upon pickup.
